# VerseMosaic public pages

These static public pages belong to **VerseMosaic**, an Android Scripture study app published by Narrow Path Doctrine Ministries.

- Home: https://narrowpathdoctrine.github.io/android-app-testers/versemosaic/
- Privacy Policy: https://narrowpathdoctrine.github.io/android-app-testers/versemosaic/privacy.html
- Support: https://narrowpathdoctrine.github.io/android-app-testers/versemosaic/support.html

The privacy page is intended for the VerseMosaic Google Play Console privacy-policy URL field, and its link should also be made accessible from the app itself.

**Maintenance:** When app permissions, cloud services, analytics/advertising dependencies, backup behavior, account features, or user-data handling change, review and update `privacy.html` and the Google Play Data safety declaration together. This website is independent of the app binary; it does not verify the current Android manifest or SDK dependency list.
